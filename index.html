Connecting to Google Sheets

  1. Open your Google Sheet. In the top menu, click Extensions, then Apps Script. A new tab will open with a code editor.
  2. In the code editor, delete all existing code, then paste in the code from the apps-script.gs file included with this app. Click the save icon (or press ⌘S).
  3. Click Deploy (top-right button) → New deployment. Click the small gear icon next to "Select type" and choose Web app.
  4. Under "Execute as" choose Me. Under "Who has access" choose Anyone. Click Deploy and accept any permission prompts that appear.
  5. Copy the URL shown (it starts with https://script.google.com/macros/s/...).
  6. Open index.html in a text editor (right-click → Open With → TextEdit on Mac, or Notepad on Windows). Find the line that says PASTE_YOUR_URL_HERE and replace it — including the quotes — with your URL. Save the file and reload it in your browser.
💡 Once configured, you can share the index.html file with your team via Google Drive. Each person does step 6 once with the same URL and is good to go.
